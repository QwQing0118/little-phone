# little-phone

一个纯前端的单文件手机界面原型。HTML、CSS、JavaScript 全部内嵌在一个文件里，双击就能打开，不需要服务器、不需要构建。

## 文件

- `index.html` —— 全部代码都在这一个文件里

## 里面有什么

- 桌面：图标网格、Dock 栏、可拖动重排
- 聊天页：消息流、长按菜单、引用回复、搜索、表情面板
- 记录 / 收着的 / 日记 / 相册 / 备忘录 / 日历
- 记忆库：卡片散落布局、连线、按分类筛选
- 设置：外观、字体、气泡、壁纸、备份导入导出
- 小游戏

## 数据存在哪

全部存在浏览器 localStorage 里，没有后端。换浏览器或清缓存会丢，设置页里有一键导出 JSON 的入口。

## 关于接口

设置页里可以填自己的模型接口（支持 OpenAI / Anthropic / Gemini 三种格式）。仓库里没有放任何密钥，需要自己填。没有填的时候，聊天页发不出消息，其他页面照常。

## 想请你看的

1. 各页面进出几轮之后有没有变空白
2. 有没有元素引用了不存在的 id、或者事件绑定漏了
3. 聊天页那套工具调用与流式解析，三家格式的兼容有没有坑
4. 有没有明显的内存泄漏或重复绑定

代码风格比较随意，很多地方是先跑通再说的写法，不用客气，哪里丑都可以说。
